نشر الموقع وتصدير الكود لـ GitHub Pages 🚀

احفظ تعديلاتك بشكل دائم لتظهر لجميع زوار العالم على GitHub Pages، أو صدّر كود الموقع المحدث بنقرة واحدة.

الطريقة الأولى: تصدير وحفظ كود الموقع (config.js)

سهلة وفورية لأي مبتدئ

يقوم هذا الزر بتوليد ملف config.js محدث بالكامل يحتوي على بياناتك الشخصية الحالية، وروابطك، وأسعارك، وأعمالك الحقيقية فقط (مع مسح كافة الأعمال والفيديوهات التي قمت بحذفها نهائياً من الكود).

خطوات تطبيق الملف على GitHub Pages:

  1. حمّل ملف config.js عبر الزر أعلاه.
  2. انقل الملف إلى مجلد js/ داخل مجلد المشروع ووافق على الاستبدال (Replace).
  3. ارفع الملفات على مستودع GitHub الخاص بك (git add . ثم git commit ثم git push).
  4. الآن سيظهر موقعك بكافة تعديلاتك الحقيقية لكل من يفتح الرابط من أي جهاز أو متصفح في العالم!

الطريقة الثانية: النشر التلقائي المباشر عبر GitHub API

بدون أوامر ولا لمس الكود

اربط لوحة التحكم بمستودع GitHub الخاص بك؛ ليتم تحديث كود الموقع على GitHub Pages تلقائياً في 5 ثوانٍ بنقرة زر واحدة من داخل لوحة التحكم، سواء من اللابتوب أو الهاتف!

يمكنك إنشاء الرمز مجاناً من حسابك: GitHub > Settings > Developer Settings > Personal Access Tokens (صلاحية repo).

تنظيف وتفريغ معرض الأعمال للبدء من الصفر

إذا كنت تجهز القالب للبيع أو تريد البدء بقائمة أعمال فارغة تماماً لوضع أعمالك الحقيقية فقط، يمكنك تفريغ كافة المشاريع الافتراضية بنقرة واحدة.
