# 🚀 CREATIVE PORTFOLIO 2026 - Ultra-Luxury Video Portfolio & Secret CMS

قالب بورتفوليو سينمائي متكامل لمنتجي الفيديو وصناع المحتوى ومصممي الموشن جرافيكس، مبني بنظام **Bento Grid 2.0 (Apple Aesthetic)**، مع **لوحة تحكم سرية سحابية كاملة** تعمل مباشرة وثابتة 100% على **GitHub Pages** بدون الحاجة لأي سيرفر مدفوع أو قواعد بيانات معقدة!

---

## 🌟 أبرز مميزات القالب:
1. **تصميم سينمائي فائق الفخامة (Bento UI):** متوافق كلياً مع جميع الشاشات (الهواتف الذكية، الأجهزة اللوحية، والشاشات العريضة بدقة 4K) مع أنيميشن سلس وسرعة تحميل 0 ثانية (Zero-FOUC).
2. **كارت تعريفي تفاعلي مع حالة العمل المباشرة (Online / Offline / In a Project):**
   * إطار احترافي مع إضاءة ونقطة نبض متوهجة لحالة الاتصال.
   * إمكانية ضبط توفرك للعمل (متاح فوراً، مشغول، متاح بعد ساعات/أيام محددة).
   * أداة اقتصاص دائري ذكية للصور واللوجو والـ Favicon مع تحكم بالزووم والتموضع.
3. **معرض أعمال وفيديوهات ريلز وسينمائية ذكي:**
   * تشغيل فوري لفيديوهات يوتيوب وفيسبوك وإنستغرام وتيك توك وفيميو وفيديوهات MP4 مباشرة.
   * مشغل سينمائي عائم (Modal Player) مع زر طلب خدمة مماثلة سريع عبر واتساب.
   * أداة استخراج الثمبنيل والتقاط لقطة الغلاف مباشرة من أي ثانية في الفيديو!
4. **نظام مقالات ودروس متكامل (Blogger Rich Editor):**
   * محرر نصوص غني بالخيارات (عناوين H2/H3، خط عريض، اقتباسات، روابط، صور، قوائم).
   * فهرس محتويات تلقائي (TOC) وزمن قراءة تقديري وصور ثمبنيل وغلاف.
5. **متجر للمنتجات الرقمية والقوالب:**
   * عرض حزم البريستات وقوالب After Effects / Premiere مع أسعار وروابط شراء مباشرة.
   * إمكانية تشغيل أو إيقاف المتجر كلياً بنقرة واحدة من لوحة التحكم.
6. **محرك التحكم بظهور وإخفاء الأقسام (👁️ 1-Click Visibility):**
   * تحكم كامل في إظهار أو إخفاء: متجر القوالب، قسم الدروس، حاسبة الأسعار، التقييمات، والأسئلة الشائعة بنقرة واحدة مع إخفائها تلقائياً من القائمة العلوية وصفحاتها المستقلة.
7. **حاسبة تسعير ذكية متعددة العملات (USD, SAR, AED, EGP):**
   * حساب تكاليف الريلز والفيديوهات الطويلة والبودكاست مع تطبيق خصومات الباقات تلقائياً.
8. **محرك تحليلات وإحصائيات الزوار المدمج:**
   * تتبع دقيق للزوار الجدد والزوار العائدين وعدد نقرات واتساب ومشاهدات الأعمال.
9. **دعم كامل للغتين (العربية والإنجليزية):**
   * تبديل فوري للغة RTL / LTR مع إمكانية تحديد لغة العرض الافتراضية للزوار من لوحة التحكم.
10. **نظام حماية وترخيص المطور المتقدم (Anti-Theft Guard):**
    * حماية ملكية فكرية للأكواد تمنع تشغيل القالب على أي نطاق غير مرخص إلا بمفتاح ترخيص رسمي صادر من مركز المطور (`developer.html`).

## 📁 هيكلية ملفات المشروع:
* `index.html`: واجهة الزوار الفاخرة الرئيسية (نظيفة تماماً وخالية من أي روابط تشير للوحة التحكم).
* `tutorials.html`: صفحة المقالات والدروس السينمائية المستقلة.
* `store.html`: صفحة متجر القوالب والملحقات الرقمية المستقلة.
* `admin.html`: لوحة التحكم السرية الخاصة بالمشتري (محمية بكلمة مرور/PIN واستعادة بيانات).
* `developer.html`: مركز المطور الخاص بك (صلاح فقط) لتوليد التراخيص وإدارة النطاقات والمبيعات.
* `css/style.css`: ملف الأنماط والتصميم الأساسي لواجهات العرض.
* `css/admin.css`: تصميم لوحة التحكم الاحترافية والنافذة المنبثقة.
* `js/config.js`: ملف الإعدادات المركزي وقاعدة البيانات الثابتة.
* `js/admin.js`: المحرك المنطقي للوحة التحكم ووظائف الرفع والتصدير والاتصال بـ GitHub.
* `js/main.js`: المحرك التفاعلي للموقع والمشغل السينمائي والحاسبة.
* `js/translations.js`: قاموس الترجمة ثنائي اللغة.
* `js/analytics.js`: محرك إحصائيات تتبع الزوار.

---

## 🔑 بيانات تسجيل الدخول إلى لوحة التحكم:
* **رابط اللوحة:** افتح ملف `admin.html` في المتصفح.
* **اسم المستخدم الافتراضي:** `admin` (أو `admin@example.com`).
* **كلمة المرور / رمز PIN الافتراضي:** `123456`
* **الدخول المباشر:** زر «⚡ دخول مباشر بـ 123456» متوفر في شاشة القفل.
* **استعادة كلمة المرور:** عبر زر «نسيت كلمة المرور؟» بنقرة واحدة أو بالبريد المسجل.

## 🚀 كيفية حفظ وتطبيق التعديلات عالمياً (GitHub Pages):
عند التعديل داخل لوحة التحكم، يمكنك تطبيق التعديلات ليراها جميع زوار موقعك في أي متصفح أو جهاز في العالم عبر الطرق التالية المتاحة في تبويب **«🚀 النشر وتصدير الكود (GitHub)»**:

### ⚡ الطريقة الأولى: استبدال ملف `config.js` (الأبسط واليدوية)
1. بعد إجراء أي تعديل داخل لوحة التحكم، اضغط على زر **«تحميل ملف config.js المحدث»** من أعلى لوحة التحكم أو من تبويب النشر.
2. استبدل الملف الذي تم تحميله بالملف الموجود داخل مجلد `js/config.js` في مجلد مشروعك.
3. ارفع الملف المستبدل إلى GitHub في ثوانٍ معدودة.

### 🌐 الطريقة الثانية: النشر المباشر عبر API
1. أدخل بيانات حسابك على GitHub والـ Personal Access Token.
2. اضغط زر **«حفظ ونشر التعديلات إلى GitHub فوراً»** ليتم تحديث الموقع سحابياً بضغطة زر واحدة.
